## Defects found by the test suite

Three real bugs, each caught before release:

**1. Caller-supplied audit trails were silently discarded.**
`AuditTrail` defines `__len__`, so a freshly created empty trail is *falsy*.
`self.trail = trail or AuditTrail(...)` therefore replaced the caller's object
with a new one, and every entry written afterwards vanished from the case
record. Caught by `test_audit_trail_records_every_artefact`, which asserted the
SQL appeared in the trail and got an empty string. Fixed with an explicit
`is not None` check and a comment explaining why the idiom is wrong here.

**2. Search extraction counted redirectors as searches.**
`google.com/url?q=…` and `google.com/aclk?…` carry a `q` parameter but are
redirectors holding a destination URL, not queries the subject typed. Matching
on host alone inflated the count from 19 to 21 and would have put URLs in a
report as things a person had searched for. Fixed by requiring a `/search` path
prefix and rejecting `q` values that are themselves URLs.

**3. Sample generation was not reproducible.**
Python's `hash()` is salted per process, so `places.sqlite` differed between
runs and could not serve as a fixture. Replaced with SHA-1-derived identifiers;
`test_generation_is_deterministic` now compares two independent builds
byte for byte.

Two smaller issues were also caught: archive entries sorted by filesystem path
rather than in-archive name, and integrity tables rendering empty Python lists
as `[]` instead of "none".
